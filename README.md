# Mu-li App

A Small cpp music player built with raylib.

## Requirements to build

- C++ compiler (GCC, Clang, or MSVC)
- Git
- Make 
- Raylib
- Visual Studio Code (optional)
- Put atleast 3 or more songs in song folder.

## How to build

### 1. Clone the repository

    https://github.com/ManasGusai/mu-li-app.git

### 2. Build the project

    debug:

        mingw32-make debug or make debug

    release:

        mingw32-make release or make release

### 3. Run the executable

    ./muli
